# Responsive Web Design v9

Study HTML structure and forms, CSS fundamentals and layout, accessibility, and responsive design. The official curriculum includes guided projects and certification projects; this notebook supplies original exercises rather than copying lesson prompts.

## Sections

- [HTML notes and practice](html/README.md)
- [CSS notes and practice](css/README.md)
- Accessibility: semantic landmarks, labels, keyboard access, and meaningful alternatives.
- Responsive layout: mobile-first sizing, flexible layouts, and media queries.
- Projects: build and test complete pages that combine the topics above.

## Suggested order

1. HTML elements, document structure, links, images, and forms.
2. CSS selectors, the cascade, box model, typography, and colors.
3. Flexbox, Grid, and responsive breakpoints.
4. Accessibility checks throughout each project.
